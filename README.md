# 📊 ETF 유동성 흐름 대시보드 — 팀 연크크

> **제12회 DB GAPS 투자대회 (2026)** 출품작
> 헤게모니 프레임 기반 ETF 유동성 모니터링 & 모의 포트폴리오 관리 대시보드

Streamlit 기반 웹 대시보드로, 대회 지정 ETF 유니버스(약 188종목)의 **가격·거래량·투자자 수급·순자산(AUM) 흐름**을 한 화면에서 추적하고, 대회 비중 규정을 지키면서 모의 포트폴리오를 운용·평가할 수 있게 만든 도구입니다.

## 팀 & 배경

| 항목 | 내용 |
|------|------|
| 대회 | 제12회 DB GAPS 투자대회 (운용기간 2026.06 ~ 08) |
| 팀명 | 연크크 |
| 투자 철학 | DB증권 리서치 『투자의 定石』의 **헤게모니 이론**을 ETF 단위 산업·국가 분석에 적용 |
| 핵심 프레임 | **구조적 헤게모니(Structural Hegemony)** — 공급 제약의 원인 자체가 구조적이어서 쉽게 해소되지 않는 산업(AI 반도체·전력인프라·방산·조선 등)에 집중 |
| 포트폴리오 골격 | 반도체 + AI 전력·CapEx + 현금성 자산(금리연계형·초단기채) |

투자 철학의 전문은 저장소에 포함된 `DBGAPS_팀연크크_투자계획서.docx` 를 참고하세요.

### 헤게모니 4국면

대시보드는 계획서의 4국면 분류를 코드(`etf_data.py`의 `HEGEMONY_MAP`)에 내장하여, ETF명·세부자산 키워드 매칭으로 각 ETF에 국면 태그를 자동 부여합니다.

| 국면 | 명칭 | 운용 기준 |
|------|------|-----------|
| 1국면 | 씨앗기 | 편입 유보, 관찰 |
| 2국면 | 황금기 | 핵심 편입 구간 (이익 컨센서스 상향 + 자금 유입 + 영업이익률 상승 동시 확인) |
| 3국면 | 출구기 | 비중 축소 |
| 4국면 | 무관심기 | 신규 편입 금지 |

## 주요 기능

대시보드는 7개 탭으로 구성됩니다.

### 1. 📊 종합 스코어보드
- 전 종목을 **7점 만점 모멘텀 점수**로 랭킹 (5일/20일 수익률, MA20·MA50 이격, 거래량 비율, 외국인·기관 5일 수급의 7개 조건 충족 개수)
- **이상신호 자동 플래그**: 괴리율 ±1% 이상 / 거래량 2배 이상 급증 / 외국인 대량 순매도(상위 10% 분위) / 기간 수익률 ±5% 이상
- 국면·수익률별 색상 스타일링 테이블, 정렬 기준 선택

### 2. 💹 자금 흐름
- 외국인·기관 수급은 **유통시장** 거래일 뿐이라는 전제 아래, ETF의 진짜 자금 유입/유출을 **총순자산(AUM) 변화**로 추정
- `순유입 추정(%) = AUM 변화율 − NAV(가격) 변화율` — 가격 효과를 제거해 순설정/순환매에 근사
- 순유입·순유출 추정 TOP 10, 세부자산군별 외국인·기관 수급 비교 차트
- 스냅샷이 **2영업일 이상** 쌓여야 활성화됩니다

### 3. 📈 모멘텀 분석
- 20일 수익률 × 거래량 비율 산점도 (색상=헤게모니 국면, 크기=AUM)
- 세부자산별 평균 모멘텀 점수 막대 차트

### 4. 🔍 개별 ETF 상세
- **TradingView Lightweight Charts** 기반 캔들 차트 (MA20/MA50 + 거래량, 최대 이력)
- 외국인·기관 일별 수급 막대 차트
- 가격 모멘텀 / 거래량 / 수급 상세 지표 패널

### 5. 🎯 포트폴리오
- 초기 가상자본 설정 → 매수/매도 원장 기록 → **평가손익·실현손익·총자산** 추적
- **대회 비중 상한 자동 체크** (위험자산 70%, 세부자산별 상한, 개별 ETF 20% 상한)
- **ETF 레이어링 룩스루**: 보유 ETF들의 상위 구성종목을 관통 합산해 `실질 노출(%) = ETF 포트폴리오 비중 × ETF 내 종목 비중` 계산 → 동일 기업이 여러 ETF에 겹칠수록 커지는 실질 노출을 시각화 (계획서 3.3의 레이어링 전략을 그대로 구현)
- 총자산 추이(equity curve) + **KOSPI / S&P500 벤치마크 대비** 성과

### 6. 🌐 매크로 신호판
- 미 10년물 금리(^TNX), VIX, 원/달러, 엔/달러, WTI, 금, 구리 실시간 모니터링
- 계획서 리스크 기준을 신호등으로 판정 — 예: 미 10년물 **4.5~5.0% 경계 / 5.0% 돌파 시 멀티플 압축 위험**, VIX 20/30 경계

### 7. 📅 이벤트 캘린더
- 운용기간(2026.06~08) 주요 촉매를 D-day와 함께 표시 (FOMC, BOJ, 빅테크 2Q 실적, 엔비디아 실적, 잭슨홀 등)

### 사이드바 공통 필터
자산 구분 / 세부 자산 / 기준 기간(1·5·20일) / 분석 ETF 수 / 헤게모니 국면 / **실시간 재수집 토글** / 대회 비중 상한 참고표

### 이중 데이터 모드
- **기본(사전 수집)**: 저장소에 커밋된 `etf_data_latest.parquet`를 즉시 로드 → 클라우드/공유 환경에서 빠르고 안정적
- **실시간 재수집**: 사이드바 체크박스를 켜면 네이버에서 전 종목을 직접 크롤링 (수 분 소요, 로컬 실행 권장)
- Streamlit `@st.cache_data`로 계층별 TTL 적용 (ETF 리스트 1h / 전체 데이터 2h / 매크로 30m)

### 일별 스냅샷 배치
`snapshot_job.py`는 ETF 핵심지표만 경량으로 수집해 `aum_snapshots.csv`에 누적합니다. 같은 날짜는 갱신(upsert)되며, 2일 이상 쌓이면 자금 흐름 탭이 활성화됩니다.

```bash
# 수동 실행
python3 snapshot_job.py

# 매 영업일 16:30 자동 실행 (crontab -e)
30 16 * * 1-5 cd "/path/to/dbgaps-etf-liquidity" && python3 snapshot_job.py
```

## 설치 및 실행

### 요구사항
Python 3.9+

### 1) 의존성 설치

```bash
# macOS / Linux
python3 -m pip install -r requirements.txt

# Windows
python -m pip install -r requirements.txt
```

주요 의존성: `streamlit`, `pandas`, `plotly`, `requests`, `beautifulsoup4`, `yfinance`, `openpyxl`, `pyarrow`

### 2) 대시보드 실행

```bash
# macOS / Linux
python3 -m streamlit run dashboard.py

# Windows
python -m streamlit run dashboard.py
```

브라우저가 자동으로 열리지 않으면 <http://localhost:8501> 로 접속하세요.
종료는 터미널에서 `Ctrl + C`.

> 터미널이 처음인 팀원을 위한 상세 안내는 [`실행_가이드.md`](실행_가이드.md) 에 있습니다.

### 3) (선택) KRX OpenAPI 연동

KRX 정보데이터시스템 OpenAPI 인증키가 있으면 환경변수로 지정 시 상장좌수·순자산총액 시계열을 추가로 활용할 수 있습니다. **키는 코드에 하드코딩하지 말고 환경변수로만 주입하세요.**

```bash
export KRX_AUTH_KEY="발급받은_인증키"
```

키가 없으면 해당 기능만 비활성화되고 나머지는 정상 동작합니다.

## 데이터 안내

- **`aum_snapshots.csv` / `etf_data_latest.parquet`** — 네이버 금융 등 **공개 소스에서 수집한 ETF 공시 정보**(총순자산, 시가총액, NAV, 괴리율, 종가)입니다. 특정 개인·기관의 실제 포지션이나 자산 규모가 아닙니다.
- **포트폴리오** — 대회용 **가상자산 모의 운용 원장**입니다. 실거래 계좌나 브로커 API와 연결되어 있지 않으며, 매매 기록은 로컬 `portfolio.json`에만 저장되고 저장소에는 커밋되지 않습니다.
- **외부 API 키 불필요** — 기본 기능은 공개 엔드포인트만 사용하므로 별도 인증 없이 즉시 실행 가능합니다.
- 수집 데이터는 **투자 참고용**이며, 크롤링 소스의 구조 변경 시 일부 지표가 비어 보일 수 있습니다.
